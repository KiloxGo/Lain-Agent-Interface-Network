# QQ 来源接入与终端管理

2026-11-06：来源入口已部署到云端（当前 schema040）与日常 Windows 安装版，原生隔离验收及
真实云端只读浏览/取消操作通过。随后只读读取器配置已安装并经公网、实际服务元数据
及六成员备份恢复验证；私人实例仍没有开启 Kernel 来源。本页不是新的采集授权。
真实接入前还需确认具体来源及其独立导入、同步、会话阅读范围。云端模型输出
上限已单独调整为8192，每轮累计仍为32768；累计额度不限不取消每轮限制或来源边界。

## 数据怎样到达 Lain

```text
指定 QQ 来源
  → NapCat 观察器本地 allowlist
  → 独立知识服务的同一来源授权
  → Kernel 已登记来源 + 独立导入保存许可
  → 有限 HTTP 读取计划
  → 当前会话的简报阅读权限
  → 单独审阅选中的记忆
```

观察器与知识服务保持独立。Kernel 只使用已配置的只读服务，不持有其管理权限，
也不改变 NapCat 登录或观察器 allowlist。来源登记、保存、同步、会话阅读与记忆分别授权。

## 在终端接入

进入 Chat，输入 `/sources`。列表或详情使用下列入口：

| 按键 | 操作 | 实际影响 |
| --- | --- | --- |
| N | 登记 QQ 来源 | 填观察账号、群号／对方 QQ 号；F5 切换群与私聊。保存身份，其他权限保持原状 |
| E | Lain 保存范围 | 为所选来源设置未来 31 天内的到期时间、文本保留分钟及本次授权最多记录数 |
| S | 有限来源同步 | 为所选来源设置到期、读取间隔、HTTP 请求总数和每次变更条数 |
| G | 当前会话阅读 | 选择此会话可读的来源、时间窗口、时区和条数，详见 DAILY_BRIEFING |

表单用 Tab/Shift-Tab 切换字段，Ctrl-U 清空，F9 显式读取本机剪贴板。
日期为 `YYYY-MM-DD HH:MM[:SS]`，时区如 `+08:00`。Enter 展示实际范围，完整阅读后
Ctrl-Y 才提交一项变更；F8 审阅停止保存／同步，仍需完整阅读与确认。Esc 关闭或返回修改。

同一来源重复登记返回已有来源，不重置已有授权。若来源实际是 Codex 档案，本入口不
提供 QQ 接入控制。所有操作使用现有 Kernel owner 鉴权，不作为 Actor 可调用的工具。

### E：保存许可

这是 Kernel 接受导入的许可，不启动任何读取。期限最长 31 天，文本保留为 1–44640 分钟，
本次授权最多 1–10000 条记录。界面默认值只是待审阅建议，不是预先启用的用户偏好。

替换保存许可会产生新的来源版本，旧版本的简报、召回及其他依赖可能不可用；同步计划
必须重新绑定当前保存版本。关闭保存后旧版本读取失效，正文按维护策略清理，不删除
QQ 平台消息，也不声称安全擦除了所有历史和独立副本。

许可建立时间不是 QQ 实际采集开始时间。消息发生时间与 Kernel 接收时间分别展示。

### S：有限同步

只从服务器已经配置的独立知识服务执行有界 GET。启用前必须有有效保存许可；同步到期
不能晚于该许可。间隔 5 秒至 24 小时，总数 1–10000 次，每次 1–32 条变更。

同步会读取服务端当前保留的片段及后续变更。它没有“仅从现在开始”的时间过滤；
不能接受历史片段时不要启用此操作，需先另行明确上游采集起点与授权方案。已有游标
按既有版本规则续接，无游标时从保留变更起点开始，不扫描 QQ 历史。

默认待审阅建议为一天、20 秒间隔、5000 次上限。现有全局读取回执累计上限为 10000，
此增量没有取消它；多日持续运行需要结合实际余量和后续维护策略，不能宣称无限连续。
每次替换都是新有限额度，旧花费保留；重启不刷新额度。失败、不确定、到期或用完停止，
不自动重试或续期。停止计划不等于删除已经保存的消息。

来源详情区分两种停止原因：本计划的已用请求达到上限，显示“本计划请求额度已用完”；
已停止但本计划仍有额度时，显示因服务的历史读取记录容量已满而停止，提示先检查服务
容量。后者不会通过单独增加本计划额度、重启或重新授权来消除；界面不会删除历史回执、
提高全局上限或自动重新发起读取。维护服务容量和重新选择有限同步仍需明确操作。

2026-11-06 Windows 本机预览版已包含此提示，可从 PowerShell 运行：

```powershell
& "$env:LOCALAPPDATA\Lain-Cloud\bin-8f3c44cca3ea\Preview-Lain.cmd"
```

这是复用现有云端连接、身份、会话和头像的独立客户端入口；启动时重读当前连接设置。
默认 `Lain-Cloud.cmd` 及其配置没有切换。此提示不需要升级云端 Kernel，不代表真实
来源已经启用；未安装该预览目录的其他电脑不能直接使用这个本机路径。

当前来源快照有既有的短新鲜度租期，长间隔或计划停止后可能暂不可读。服务端有配置、
凭据存在、HTTP 成功与 QQ 正在持续接收是不同事实。

## 服务器读取配置与审阅绑定

2026-11-06 实际安装：现有 HTTPS、store 身份及独立读取凭据已配置到 Kernel。
读取 JSON 以 root:lain0640 保存，凭据仅由私有环境间接引用；环境、原 Actor/NapCat
及读取 JSON 都已纳入明确选择的备份。真实六成员备份独立恢复通过，公网读取器状态
核对了新启动代次及配置指纹。另一次上游状态查询验证只读凭据和 store，没有请求
消息、变更或图片正文，没有创建来源或阅读授权。原数据库/身份及试用期限保留。

备份工具可选 `--knowledge-config` 的20项原生 Linux合成/CLI检查属于前置证据；
配置安装另有9项文件/恢复回归及9项真实隔离 systemd/SQLite/HTTP案例。不能把这些
检查或当前“配置与凭据可用”当作个人消息接收正常。来源选择问题仍待答复，
Kernel 来源仍为0，真实QQ简报与记忆闭环尚未验收。

服务器管理员仍按 KNOWLEDGE_BRIDGE_ACCEPTANCE 配置受保护的 `LAIN_KNOWLEDGE_CONFIG`：
固定 HTTPS 服务、实际 store UUID 与间接 SecretRef。凭据通过其私有环境提供，不从终端
输入，不写入仓库。观察器及服务端实际来源选择按 `services/qq-knowledge/README.md` 操作。

`GET /v1/archives/knowledge-reader` 或 `lain archive knowledge-reader` 仅返回：

- `configured`：配置可加载且格式有效；否则可能未配置或配置无效。
- `credentials_available`：对应环境凭据可解析，不证明远端接受它。
- `revision`：有效配置指纹，不含 URL、路径、SecretRef 或密钥。

该接口使用 owner 鉴权和 no-store，不访问外部服务、不调用模型。新终端启用 S 时将审阅的
指纹作为 `SetKnowledgeSync.expected_reader_revision` 发送，Kernel 在保存启用决定前核对。
配置已更换时拒绝，要求重新审阅。撤销不要求读取配置仍存在。该字段可选，旧显式 API
调用保持兼容；它不是新的数据来源授权。存储表和既有 reader_revision 的权威不变。

## 同步、关闭与未知结果

来源元数据变化会撤下旧审阅和确认门禁。未发送字段仅在同一入口及不可变来源身份下
保留；重新读取最新来源、保存版本和 reader 后恢复字段，仍需重新 Enter 和完整审阅。
重读期间的输入与粘贴不会写进隐藏聊天草稿。Esc/导航放弃草稿和打开意图，迟到 GET
不能重开已关闭的表单。系统失效保留结果导航意图，主动关闭后不会跳到结果页。

提交前重新检查来源身份、版本、到期及读取配置；Kernel 继续做真实的原子校验。
未知写入不重发。Ctrl-R 仅查询来源和目标版本的服务器记录，按实际 scope 与 reader
匹配。旧登记／保存／同步 API 没有请求 ID，因此相同记录不证明来自本次请求，也不证明
它仍是当前权限；界面仅报告找到了同样配置，当前状态另行刷新。

400 可能发生于提交后的响应检查，先核对记录再判定。网络错误后暂未查到记录仍为未知，
不证明在途请求不会稍后生效。确实无法核对时，读完警告后 Ctrl-D 只放弃本机跟踪，不
撤销原请求、不自动重发；继续操作前须重读当前状态。退出客户端也不会撤销服务端决定。

## 状态与验证边界

来源详情展示许可、实际最后接收、来源报告时间、保留文本数、读取结果、请求使用量和
停止原因。接收连接仍可能未知；源缺口、上游快照、导入保存和阅读权限保持区分。

`scripts/source_setup_smoke.py` 使用隔离 Kernel、原生 Windows ConPTY 和合成 HTTP 来源，
从空列表执行 N/E/S，实际保存一条投影、第二次按游标读空增量、停止及重启无重放。
不连接真实 QQ，不调用模型，不访问个人数据。原有 G 授权独立验收。截图是 ConPTY
离屏渲染，不证明真实 QQ、用户字体、多日接收或其他平台通过。

来源管理与读取器配置已完成云端部署。剩余范围是待答复的真实来源选择及其观察器／
服务端 allowlist 应用、真实 QQ 简报闭环，以及长期额度／存储维护；既有部署和隔离
验收不替代这些真实接收证据。
