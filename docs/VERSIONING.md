# 版本策略

项目采用 Semantic Versioning 2.0.0 的 `MAJOR.MINOR.PATCH` 结构，但在 `1.0.0` 之前视为实验性私有软件。

- PATCH：不改变公开协议和持久化语义的缺陷、安全与内部性能修复。
- MINOR：向后兼容的新能力；在 `0.x` 阶段也用于明确记录协议、配置或数据结构变化。
- MAJOR：公开协议、数据兼容性或安全模型的破坏性变化。

当前版本为 `0.1.0`。在首次正式制品前，版本来源统一收敛到 workspace/release 配置；当前 Cargo 版本是临时单一事实来源。

每次版本变化必须更新 CHANGELOG，并说明：用户可见行为、WebSocket/API 兼容性、数据库迁移、配置变化、安全影响与回滚方式。人格提示词、记忆策略或评测阈值的变化即使不改变 API，也必须进入 CHANGELOG。

仓库保持私有且未授予代码许可证；选定许可证之前不得对外发布源代码或二进制制品。许可证选择不改变第三方角色、商标、模型或素材的独立权利边界。
