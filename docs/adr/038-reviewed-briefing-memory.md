# ADR 038: Reviewed briefing selection into conversation-local memory

Date: 2026-11-05. Status: selected for implementation; not deployed or fully accepted.

## Boundary

A briefing read grant is not a standing memory grant. Add one typed
`briefing.remember` proposal selecting an actual immutable briefing/item; the
Kernel derives its cautious episodic draft, scope and provenance. The existing
exact Actor action review authorizes this one write. Neither ordinary chat assent
nor model output can approve it. The existing private-memory trial is unchanged.

Use real Conversation memory scope and origin, not forged QQ identities or
ambient Global memory. Another conversation, device or project does not inherit
this source/visibility. Source archives, reports, memory and operation receipts
remain separate. This adds no second semantic store or Worker intelligence.

The selected draft is fixed from the stored model item, including uncertainty
and nonparticipation language; a model cannot rewrite arbitrary text and attach
convenient citations. Evidence retains the exact item/extraction turn, selecting
turn/action, briefing-grant revision and every input record of that extraction
batch (up to four), including uncited inputs. Review is selection, not verified
truth: authority is UnverifiedSelection even after explicit confirmation.

Prepare/review require current manifest and sources. Saved recall checks the
original audience/read epoch, record revisions, import grants, upstream freshness,
retention and suppression. Its finite expiry is no later than the original read
grant, source grants and retained inputs. The manifest's short operational lease
does not itself erase a selected memory; its underlying finite source authority
still must remain valid. No authorization renewal silently revives old epochs.

Use existing memory candidates, records, FTS, revisions, context dependencies and
invalidation. New schema036 gates the new JSON meaning from old binaries and
adds only conversation-keyed source suppressions, not enabled grants. Exact
accepted receipts remain historical metadata; they never replay writes or restore
withdrawn bodies. Generic promotion from briefing influence stays blocked.

## Remaining implementation/acceptance

Local selection, same/cross-conversation recall, source withdrawal, suppression,
retention and interrupted-ack restart now have deterministic regression evidence.
The normal Actor tool path reads the report, proposes a fixed draft, waits for
actual review and later recalls the record. Both terminal confirmation surfaces
share draft validation. Native Windows terminal/simulated QQ acceptance now
passes; actual DeepSeek over synthetic sources also passes selection/review/
recall, restart and source withdrawal. No live-source QQ or production upgrade
is claimed.

Pending review checks the actual candidate as well as manifest/source currency;
suppression after another selection is forgotten closes it without writing.
Candidate insertion wakes archive maintenance for its earlier finite deadline.
Accepted candidates project typed content-free reviewed-memory receipts even if
the action acknowledgement never committed or source bodies are withdrawn.
The checked terminal history rebuild reapplies only typed metadata cards after
all withheld turns, so later withdrawn reads cannot erase earlier save facts.
Natural correction/forget requires separately typed, reviewed operations over a
real current-user statement and inspected revision; do not fake IncomingIds or
weaken current private tools. Cross-batch correction and the full QQ/terminal
save/recall/correct/forget flow remain required by the active goal. No live source,
production migration, public release or autonomous standing write follows from
this ADR.
