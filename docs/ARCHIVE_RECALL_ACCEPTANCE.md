2026-10-27 (Asia/Shanghai). Contract: [ADR 021](adr/021-scoped-archive-conversation-recall.md).
This is a W1 continuity slice, not completion of W1, daily companionship or the
combined goal. The independent QQ knowledge service remains separately deployed.

## Behavior

An independent default-off private-binding recall decision selects exact source/
import-grant epochs and a finite expiry/timezone. It exposes bounded stored
archive search/inspect to private chat, without collecting or controlling a
source. Source details/text follow a lookup; automatic capability context lists
Lain source IDs/epochs only. Source occurrence claims and Kernel receipt time,
observed/owner-corrected origins and partial coverage remain inspectable.

Every lookup keeps a grant/record dependency, including an empty match. Fresh
evidence and IDs-only audits precede further inference. Adapter-entry, response,
commit and delivery guards reject stale influence; subsequent model history and
private source projections cannot replay derived answer bodies. Memory proposal/
remember/correct from an influenced turn is blocked pending proper derived-memory
provenance. No extra planner, scheduled model call, experience or Worker control.

## Operation in five steps

1. Use an isolated/dev instance or a separately authorized stopped full backup/
   upgrade. Schema19 is forward-only; the personal schema16 instance has not been
   upgraded here. Rollback restores the complete old instance with old binaries.
   The old D3 `prepare_daily_release.py` intentionally remains schema16-only; it
   must not be used to stage these schema19 binaries for the personal instance.
2. Register/enable/import or explicitly read a selected archive source using the
   existing archive commands. Inspect its actual source ID and grant revision.
3. Inspect `lain archive recall-grant <channel>`, then write an explicit JSON file
   with `expected_revision` and `scope`: `sources` contains exact `source_id` and
   `grant_revision` pairs; also provide `expires_at_ms` and `utc_offset_minutes`.
   Run `lain archive recall-enable <channel> --file <file>`.
4. Ask in the selected private conversation about the date/topic. Inspect the
   Actor's archive action/versions and `archive recall-reads <channel> --after 0`;
   excerpt truncation and source claims do not prove full reading/verification.
5. Correct/forget with existing archive commands, or run `archive recall-revoke
   <channel> --revision <current>`. This stops future disclosure and stale drafts;
   already dispatched provider requests, past delivered messages and backups are
   not retroactively erased.
