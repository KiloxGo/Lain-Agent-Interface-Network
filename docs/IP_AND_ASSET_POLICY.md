# 知识产权与素材策略

本项目名称与人格方向可能使使用者联想到既有作品或角色，但技术实现、原创设定、第三方素材许可和商标使用是不同问题，必须分别管理。

## 当前边界（KiloxGo 于 2026-08-11 确认）

- 项目暂时保持私有。仓库当前没有根级开源许可证，因此不能假定代码已获开源再分发授权；在 KiloxGo 选定许可证前，不对外发布源码或正式发行包。
- 不提交来源不明的角色立绘、Live2D 模型、动画、音频、字体、台词语料或训练数据。
- 不以抓取影视/游戏/漫画台词作为人格评测或提示词数据。
- 任何第三方资源进入仓库前，记录来源、作者、许可证、修改许可、商业使用、署名要求和再分发范围。
- CI/发行流程只打包显式登记的资源；本地个人资源通过忽略目录加载。
- 当前不分发任何第三方 Lain、Live2D、音频、字体或其他角色素材。

## 资源登记最小字段

`asset_id`、文件路径、来源 URL、权利人、许可证标识/原文副本、允许用途、署名文本、获取日期、校验和、审核人。缺一则默认禁止分发。

## 人格实现原则

人格通过原创的行为原则、语言约束、关系状态和评测目标实现，不通过大段复制受保护表达来模拟。任何公开品牌/角色定位应在发布前接受独立的法律与平台政策审查。
