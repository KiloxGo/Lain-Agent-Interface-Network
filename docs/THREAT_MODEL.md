# 威胁模型

状态：P0 初版。范围是单用户、本机优先的 Web UI + Rust 后端；未来公网访问、多用户、外部工具和主动消息均不在当前信任边界内。

## 资产与信任边界

高价值资产包括模型 API Key、会话内容、长期记忆、身份/关系状态、工具权限、系统提示词和审计记录。浏览器、后端、模型供应商、文件/数据库、未来工具进程之间均视为独立信任边界。

## 主要威胁与默认缓解

| 威胁 | 影响 | P0/P1 缓解 |
|---|---|---|
| 密钥提交或日志泄露 | 账户与费用损失 | `.env` 忽略、示例空值、日志禁止输出 Authorization、CI secret 扫描后续接入 |
| Prompt injection 操纵记忆/工具 | 持久化污染或越权 | 模型文本不直接执行；结构化意图经过策略层、schema 校验和权限判断 |
| 跨会话/跨用户记忆串扰 | 隐私泄露 | 每次查询强制 scope；未知 scope 拒绝；隔离 fixtures 和负向测试 |
| 敏感信息过度记忆 | 长期隐私风险 | 默认不自动写入敏感类别；同意、来源、保留期与删除能力进入记录 |
| WebSocket 冒充、重放、乱序 | 错误操作或状态破坏 | 本地绑定、协议版本、event/run/session ID、序号、幂等与取消语义 |
| 路径穿越/任意文件写入 | 主机数据受损 | 不让模型提供原始路径；存储层生成 ID 和规范路径；原子写/事务 |
| 恶意或异常模型输出 | UI 注入、解析失败 | 前端按文本渲染；事件 schema 严格校验；未知事件安全忽略并记录 |
| 资源耗尽 | 延迟与费用失控 | 上下文预算、输出上限、超时、并发/队列上限、取消传播和速率限制 |
| 供应链依赖风险 | 构建或运行时被攻破 | lockfile、固定工具链、最小 CI 权限、生产审计、cargo-deny 策略 |
| 删除不完整 | 用户无法控制数据 | P1 建立可验证的级联删除、导出和 tombstone/审计策略 |

## 数据分类

- Secret：API Key、令牌；不得进入持久日志或客户端。
- Sensitive：真实身份、健康、财务、精确位置、亲密关系；默认不长期记忆。
- Personal：偏好、关系状态、对话摘要；必须有 scope、来源、保留与删除规则。
- Operational：事件 ID、时延、token 数、错误码；默认不含原文。
- Public/Synthetic：代码内示例与合成 eval，可版本控制。

## 安全不变量

1. 模型永远不是授权主体。
2. 未知身份或 scope 不能退化为全局访问。
3. 记忆检索失败不得扩大检索范围。
4. 工具副作用默认需要明确策略许可，敏感副作用需要用户确认。
5. 日志和遥测默认不记录完整 prompt、回复、密钥或敏感记忆。
6. 删除、导出、撤销同意必须不依赖模型配合。

## 待验证

P1/P2 必须补充：协议 fuzz/property tests、跨 scope 泄露测试、迁移回滚测试、日志脱敏测试、取消与超时测试、恶意 tool arguments 测试。任何远程访问设计需要独立威胁模型和认证 ADR。
