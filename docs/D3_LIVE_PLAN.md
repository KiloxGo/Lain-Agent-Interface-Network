The 12 personal requests cover reading, drafts, any ordinary real incoming chat,
tools and reconsideration together. The 2+2 activity caps are intersections, not
extra allowance. No model judging outside either partition. The replay can be
analyzed automatically; the owner need not send test messages. A subsequent real
incoming question may supply recall evidence, but lack of such evidence stays
pending and never justifies forged owner input.

Any selected bridge must have verified no hidden retry/fan-out. If that cannot
be established within the authorized inspection scope, paid replay stays off;
report the concrete finding instead of treating an adapter ledger as a precise
provider bill. Token/fee uncertainty remains explicit even with verified attempts.

## Upgrade, closure and rollback

1. After the actual new decision, fingerprint the immutable package and exact
   non-secret Actor config; record the two budget IDs and fixed deadline outside
   the personal instance's backup/rollback subtree. Inspect current state and
   active work. Do not terminate accepted work to clear the installation path.
2. Stop/drain the original instance gracefully, preserving its actual launch
   method. If its original foreground window is unowned, coordinate one Ctrl-C
   instead of silently force-killing it. Make and verify a complete stopped backup
   including ACL-protected credentials, database/sidecars, config, binaries and
   entry points; display hashes/status only, never file secrets.
3. Migrate a protected copy first. Bootstrap the selected new binaries without
   model/QQ config, install that instance's approved finite budget, then restart
   with approved settings. Never open an unmetered legacy-compatible response
   window before installing the budget. No database copying for identity sync.
4. Execute isolated real-model replay and bounded actual-source/QQ checks, keeping
   real model + simulated transport, real acquisition/contact, subjective quality
   and missing multi-day evidence distinct. Expired/DND/skip/unknown outcomes do
   not authorize another send, new source or extra request.
5. At the boundary revoke reading/contact/temporary memory independently, set DND
   and stop both model budgets. If necessary, restore the **complete matching**
   stopped backup and old entry point; close the external campaign record. Never
   continue paid trials on a rolled-back daemon that lacks the budget gate.

An opted-in budget stays stopped/expired/exhausted after this campaign. The new
daemon consequently cannot continue model replies without another explicit finite
budget decision. Do not silently restore unlimited compatibility mode. Source and
derived-content expiry does not delete independent operational receipts or the
protected rollback backup; report those retention distinctions.
